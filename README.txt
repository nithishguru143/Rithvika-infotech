# Rithvika Infotech Website

Responsive static website based on the supplied Rithvika Infotech branding and banner.

New in this version:
- Animated software/network Lottie section using a local JSON animation.
- CSS keyframe effects for data packets, live system status, grid motion, banner sweep and service icons.
- Reduced-motion accessibility fallback.
- Lottie Web is loaded from jsDelivr; the animation JSON itself is bundled locally in assets/.

Files:
- index.html
- style.css
- script.js
- assets/ (images + software-network-pulse.json)
