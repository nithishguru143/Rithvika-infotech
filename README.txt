# Rithvika Infotech Website

Responsive static landing page based on the supplied Rithvika Infotech and Sathyaraj A visiting-card artwork.

Files:
- index.html
- style.css
- script.js

Open `index.html` directly in a browser or upload the three files to any normal web host.

The contact form opens WhatsApp. Replace the WhatsApp number in `index.html` / `script.js` if the business number changes.
